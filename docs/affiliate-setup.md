# アフィリエイト運用手順

2026-07-18導入、2026-07-19に配信バッジへのリンク埋め込み方式に変更。
VODアフィリエイトの提携〜リンク登録〜月次更新の手順。
実装の全体像: サービスごとに複数ASPのリンクと報酬額をデータ登録し、**配信バッジ自体の
リンク先**として、その時点で報酬額が最大のactiveなリンクを自動採用する（コード変更不要）。
アフィリエイトが無いサービスのバッジは自動で公式サイトにリンクする（フォールバック）。

## 仕組み（どこに何があるか）

| 役割 | 実体 |
|---|---|
| リンク・報酬額のデータ（人力更新） | `content/affiliate/programs.ts` |
| 最高報酬リンクの自動選択 | `lib/affiliate.ts` の `pickAffiliate` |
| 公式サイトURL（フォールバック先） | `lib/services.ts` の `SERVICES[].officialUrl` |
| バッジのリンク化＋PR開示文の表示 | `components/ServiceMarks.tsx` |
| 表示箇所 | 配信バッジが出る全ページ（作品個別・シーズン一覧カード・サービス別） |
| クリック計測 | `affiliate_click`（アフィリエイト時）/ `official_link_click`（公式サイト時）。`/admin/analytics` で確認 |
| 開示ページ | `/privacy`（広告掲載方針・ステマ規制対応） |

**バッジの表示件数はアフィリエイトの有無で変わらない**（2026-07-19方針）。
アフィリエイトが無いサービスも従来どおりバッジとして表示され、リンク先が公式サイトになるだけ。
`content/affiliate/programs.ts` が未登録・全て `active: false` でも、
全バッジが公式サイトへのリンクとして機能する（＝提携前にデプロイしても安全）。

## 初回セットアップ（ユーザー作業）

1. ASPに登録する（無料）: A8.net・afb・バリューコマース・アクセストレード＋Amazonアソシエイト。
2. 各ASPでVOD案件（U-NEXT・DMM TV・ABEMA等）に提携申請する。
   審査には運営者情報の記載が必要（`/about` 整備済み）。Leminoはドコモアフィリエイトのみ。
   Netflixはアフィリエイト提携不可（2026-07調査）。
3. 承認されたら管理画面でリンクを発行し、`content/affiliate/programs.ts` に
   `{ asp, url, rewardYen, rewardNote, confirmedDate, active: true }` を追記する
   （ファイル内の記入例参照）。Claudeに「〇〇のアフィリエイトリンクを登録して」と
   依頼し、リンクと報酬額を貼り付ければ追記・検証まで行う。

## 月次更新（5分。ここだけは自動化できない）

報酬額はASP管理画面（ログイン制）でしか確認できないため、月1回:

1. 各ASPの管理画面で現在の報酬額を確認する。
2. 変わっていたら `programs.ts` の `rewardYen` と `confirmedDate` を更新する
   （Claudeに数字を伝えれば更新する）。**更新すれば採用リンクの切替は自動**。
3. 案件停止・提携解除されたものは `active: false` にする。

## 規約・法令上の注意（2026-07調査の要点）

- **広告である旨の表示**: 2026-07-27にバッジ上の「PR」タグ（`.svc-chip-pr`）は廃止し、
  ①バッジの`title`属性（「〜（広告リンク）」）と②開示文（`.svc-disclosure`、バッジ列の直後）に
  一本化した（消費者庁ステマ規制Q&A Q13: 冒頭の一括表記だけでは不十分とされる）。
  カード一覧のように同じバッジが繰り返される画面では`hideDisclosure`でバッジごとの開示文を止め、
  **呼び出し側が画面につき1回だけ開示文を出す**（`components/SeasonExplorer.tsx`）。
  開示文をどこにも出さない画面を作らないこと。表示文言は`/privacy`の記載とも同期させる。
- **ロゴ・素材**: VOD各社はASP提供素材の権利を自社に留保し、画面キャプチャや
  ドメインへの商標使用を禁じている場合がある。本実装はテキストバッジ方式のため
  ロゴ問題を回避しているが、バナー掲載に変える場合は各社ガイドラインを確認する。
- **リンク属性**: アフィリエイトリンクは `rel="sponsored nofollow"`、公式サイトへの
  フォールバックリンクは `rel="noopener noreferrer"`（実装済み）。
- 成果条件（例: Leminoは32日間継続で成果確定）は `rewardNote` に記録しておく。
- **公式サイトURL** (`SERVICES[].officialUrl`) は各社トップページのみ（2026-07-18時点で
  一次情報確認済み）。ドメイン変更等に気づいたら都度更新する。

## 提携の優先順位（2026-08-06 実測。報酬10件を最短で取りにいくための順番）

### いまの状態

提携済みは **ABEMA と Amazon Prime Video の2件だけ**（`content/affiliate/programs.ts`）。
残りのバッジは公式サイトへのフォールバックリンクなので、押されても1円にもならない。

自サイトのスナップショット（`content/snapshots/` の2024〜2025年・8クール・1,444作品）を
集計した実測値:

| 指標 | 値 |
|---|---|
| 配信サービスが1件以上ある作品 | 648 / 1,444 |
| 画面に出る配信バッジの総数 | 4,397 |
| うち**提携リンクになっているバッジ** | 978（**22.2%**） |
| 提携リンクが1つ以上出る作品ページ | 523 / 648（80.7%） |

**読み方**: 作品ページの8割には既に提携リンクが1本以上出ている。足りないのは
「リンクが無いページ」ではなく、**押されているバッジの8割近くが収益にならない**こと。
つまり伸びしろは提携サービスを増やすことにある。

### 複数ASPがあるときの選び方（2026-08-06にユーザーが明示）

**報酬額が多いほうを使う。** これは既に `lib/affiliate.ts` の `pickAffiliate` の挙動
そのもの（active のうち `rewardYen` が最大、同額なら `confirmedDate` が新しいほう）なので、
実装変更は不要。**同じサービスで複数のASPと提携できたら、全部 `programs.ts` に登録して
よい**（採用は自動で最高額に切り替わり、片方が停止しても `active: false` にするだけで
次点へ落ちる）。現に Prime Video は afb（845円）とバリューコマース（836円）の両方を
登録してあり、afb が採用されている。

### やること（ユーザー作業。ASP管理画面はログイン制でこちらから見えない）

1. **dアニメストア**の提携を申請する。掲載本数1位かつアニメ専業で、
   「作品名＋配信」で来た人の意図に最も近い。Leminoと同じくドコモ系なので
   **ドコモアフィリエイト**を先に確認する。
2. 次に **DMM TV → U-NEXT → Hulu**。いずれも主要ASP（A8.net・afb・
   バリューコマース・アクセストレード）のどれかに案件がある想定だが、
   **どのASPが扱っているかは管理画面でしか確認できない**ので、こちらでは断定しない。
   実際に見つかった案件と報酬額を教えてもらえれば `programs.ts` に追記する。

   **どのASPから当たるかの候補**（2026-08-07調査。出典は
   `docs/research-2026-08/research-F.md`）。**いずれもASP解説記事・個人ブログ発の
   二次情報で、案件の有無・単価は管理画面で見るまで確定しない**。当てずっぽうで
   探すより始点があるほうが早い、という程度のもの。

   | サービス | 見つかったという報告のあるASP |
   |---|---|
   | DMM TV | アクセストレード、afb（この2つが高いという記述） |
   | U-NEXT | JANet、Link-A（有力候補）／A8.net、バリューコマース |
   | Hulu | アクセストレード、バリューコマース |
   | ABEMA（提携済み） | afb、アクセストレード、A8.net、バナーブリッジ |
   | dアニメストア | **報告が見つからなかった**。ドコモアフィリエイトを先に確認する |

   なお **Netflixは提携先そのものが存在しない**（上表で「提携不可」としている根拠は
   2026-08-07の再調査でも変わらず）。ここに時間を使わないこと。

   **ASP登録の審査について**: PV数の下限を明記した一次規定は見つからなかった。
   審査で見られる要素として繰り返し挙がるのは記事数・内容の質・独自性のほうで、
   バリューコマースは「10記事程度書いてから」を目安として挙げている。
   **月128人という規模を理由に申請を見送る根拠は無い**ので、まず出す。
3. 承認が下りたら報酬額つきで連絡する。採用リンクの切替は `pickAffiliate` が自動で行う。

### 順番を決め直すときの一次情報

上の表は「掲載本数」による推定にすぎない。**実際にどのサービスのバッジが押されているか**は
サイト自身が2026-07-19から記録している（`official_link_click` ＝未提携サービスへのクリック、
`affiliate_click` ＝提携済みへのクリック。どちらも `event_data.service` にサービスキーが入る）。

ただし**2026-08-06までダッシュボードにこの2イベントが1つも表示されていなかった**
（`app/admin/analytics/page.tsx` の `EVENT_LABELS` に載っておらず、表もグラフも
このリストから作られていたため）。同日、イベント別件数への追加と、サービス別の内訳
パネル2つ（未提携／提携済み）を追加した。

`/admin/analytics?token=...` の **「未提携サービスへのクリック」が多い順**に提携すれば、
掲載本数からの推定ではなく実測に基づく順番になる。上の表よりこちらを優先すること。
`ADMIN_DASHBOARD_TOKEN` が未設定なら、まずそれを設定するのが先（設定するまで
このダッシュボード自体が開けない）。

### 報酬10件をどう数えるか

成果件数はASPの管理画面にしか出ない（こちらからは取得できない）。
`/admin/analytics` で分かるのは**クリック数まで**で、成果（登録完了）ではない。
月次更新（上記「月次更新」）のついでに、各ASPの成果件数を控えておくと進捗が分かる。
