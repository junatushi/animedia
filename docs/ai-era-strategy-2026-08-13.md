## 0. 結論（3行）

1. **10億円の経常利益は、いまの器（日本語アニメ配信ガイド＋VODアフィリエイト）では到達しない。**
   実測単価（845〜2,368円）から逆算すると、転換率1%なら**月556万訪問**（現在の約4.3万倍）、
   実質上限とされる3%でも**月185万訪問**（現在の約1.4万倍）が要る（現在＝月間訪問者128人）。
2. **しかもその「訪問を増やす」という機構そのものが、いま縮小している。**
   ゼロクリック68%、AI概要出現時のCTR低下34.5%、日本のAI検索利用率は8ヶ月で3.5倍。
   実質上限の転換率（3%）で見ても1.4万倍（1%なら4.3万倍）を、縮んでいる配管で狙うことになる。
3. **同カテゴリで10億円規模に到達している唯一の実例（JustWatch）は、器が違う。**
   消費者向けは無料の入口で、収益はB2B（配信可否データのライセンス＋スタジオ向け広告運用）。
   本サイトが3ラウンドの調査で辿り着いた「データ供給元になる」という結論は、
   **偶然にもその器の入口と同じ形をしている。** 集客戦略ではなく事業構造の話として続ける。

## 3. 選択肢

### A（本命）: AIに引用される「日本語アニメ配信の事実レイヤー」になる

やること: 既にある公開API・ウィジェット・帰属義務ライセンスを、
**AIとエージェントが読む前提**で作り直す。具体的には
①`Dataset` / `JSONFeed` 型の構造化データと schema.org の整備、
②`lib/services.ts` の名寄せ表の公開データセット化（1章の①・法務的に今すぐ出せる）、
③ChatGPT App Directory への提出（2-7）、
④一次データ（平均9.0社・独占4%）を**プラットフォーム側**（note / PR TIMES）に置いて引用経路に載せる（2-4）。

| | |
|---|---|
| 利点 | 既存資産のコード修正だけ。AI経由は転換率が高い（2-3）。3ラウンドの調査結論と同じ向き |
| 欠点 | AI流入は全体の0.32%＝**いま食える量ではない**。引用されてもリンクが返る保証がない。効果測定が構造的に難しい |
| 工数 | 小〜中（②③は各半日、①は1日、④は文章作成） |
| 撤退 | 容易（全て追加物。既存の動作を壊さない） |

## 4. 推奨

**Cを止めずに、Aを今すぐ始める。Bは「Aの副産物として条件が揃ったら」に置く。**

根拠の強さを明示すると:

| 判断 | 根拠の種類 |
|---|---|
| 「アフィリエイト単体では10億円に届かない」 | **数字**（実測単価×必要転換率。1章） |
| 「検索流入という機構が縮んでいる」 | **数字**（ただし二次情報。2-1／2-2） |
| 「AI経由はいま量が無い」 | **数字**（0.32%。2-3） |
| 「引用されるのはプラットフォーム。独立サイトは一次データで名前を取るしかない」 | **理屈**（2-4の観測からの推論） |
| 「B2Bが10億円に届く唯一の器」 | **1件の実例**（JustWatch。n=1） |

**Aを推す理由は「いま儲かるから」ではなく、Aだけが C と B の両方に効くから。**
- Cに効く: 構造化データと一次データの発信は、いまの検索流入も落とさない
- Bに効く: 「AIとエージェントが読める形で配信データを持っている」状態そのものが、B2Bの商品の前身

逆に、**Aをやらない場合に失うもの**は「AI検索が日本で3.5倍になった1年」に何も置かなかったこと。
巻き返しのコストは、いま置くコストより明確に高い。

**⚠ 正直に**: A を全部やっても、**3ヶ月では数字は動かない可能性が高い**。
AI流入0.32%という母数がそれを示している。Aは「近い目標のための施策」ではない。
