## 踏んだ落とし穴（再発防止）

- **dev server起動中に`rm -rf .next && npm run build`すると`.next`キャッシュが破損する**
  （`Cannot find module`等）。ビルド前に必ず`preview_stop`してから。
- **`gh` CLIはこの環境に入っていない**。GitHubのIssue・Actions実行履歴を見たいときは、
  リポジトリが公開なので`https://api.github.com/repos/junatushi/animedia/...`をWebFetchで直接叩く。
- **ブラウザのスクリーンショットが撮れないことがある**（Browser paneが非表示だと
  「not compositing frames」で失敗）。表示内容の検証は`fetch`でHTMLを取り、
  title・meta・特定クラスの出現回数を数える方が確実で速い。
- Annict GraphQLスキーマにレンタル/サブスク区別フィールドは無い（introspection確認済み）。
  レンタル判定はdアニメ検索API（`vodType`）かWeb検索での個別確認が必要。Amazon直接アクセスはbot判定でブロックされる。
- サーバー/クライアントで年・シーズン解決ロジックがズレるとSSRの`initialData`と表示が
  食い違う。`lib/resolveSeasonParams.ts`に共通化済み、変更時は両方への影響に注意。
- `ServiceTag.key`は`string`型（`lib/types.ts`）。`lib/services.ts`のヘルパーは
  `getOfficialUrl`同様`string`を受けてマップ側でキャストする形に揃えること。
