  - 該当しないもの: ページへの作品情報の表示（第6条の対象外）、`/api/services`（自前の名寄せ表）。
  - 対応の選択肢（利用者の判断）:
    - (a) リポジトリの非公開化。GitHub Actions は直近30日で約1,530分（718回）、非公開の無料枠は月2,000分。

    - 15.5 は `.segments` を書かない。`collectSegmentData` の中で `experimental.clientSegmentCache !== true`（既定 false）なら何もせず戻る。
    - next 本体への `npm audit` 勧告は無し。

    - いずれも実ビルドでの確認はまだ。

### ホスティング
- **Vercel Hobby のままでは収益化できない**（広告・アフィリエイトは規約で不可、寄付のみ可＝Vercelサポートが2回回答）。Annict の側の障害は無くなったので、残る壁はホスティングだけ。
- **Hobby の継続そのものも安全ではない**。Next 14 のままで ISR Writes 261K/200K、Active CPU 3h34m/4h。公式は「超えたら30日経つまで再利用不可」「超過が続くと一時停止（503）」。止まる閾値は分からない。
- **Vercel Pro は予算外**（月$20＝約2,800〜3,300円）。従量分は約$5でクレジット内。
- 利用者の条件（収益化に問題があれば月1,000円まで）は**すでに成立している**。払うかどうかは利用者の判断で、判断材料は次のとおり:
  - 費用: Cloudflare Workers Paid＋ドメインで月約830〜1,040円（税は未確認）。VPS（さくら512MB〜1GB）＋ドメインで月約720〜1,150円。
  - 回収見込み: アフィリエイトで月約120〜1,230円（一次単価×仮定の転換率）。ただし停止前の約2か月は**成果0件**（8/13時点）で、転換率の仮定は高すぎる疑い。広告は見込みから外す（後述）。
  - つまり**いまの利用数では費用の半分前後かそれ以下**しか回収できない見込み。
- 払う場合の移行先は**本命を決め打ちしない**。Cloudflare Workers Paid と VPS を各1週間ほど試作して、「最悪の月額」と「人の手間」で選ぶ。
- 無料のまま商用可の候補はどれも成り立たないか未確認:
  - Workers Free: CPU 10ms/req。実測120ms。
  - Netlify Free: デプロイだけで300クレジットを超える。
  - 完全静的化: 約3万ファイル＞無料の上限2万。
  - Deno Deploy: 商用可否と revalidateTag が未確認。
- Vercel を離れるなら**独自ドメインは必須**（vercel.app は持ち出せない）。移す時期は11月中か2月にする。12月は冬クールの検索需要が立ち上がる時期なので、順位の揺れを重ねない。

## 3. セキュリティ
- **最大の論点**: Hobby で 16 へ上げると ISR Writes が増えて止まりうる。セキュリティ更新が無料枠で止まっている状態。15.5.29 でこの対立は2027-01-31まで解ける見込み。
- Vercel の基盤側の守り:
  - 実績: React2Shell では公表前に全利用者へWAFルールを配布、脆弱版のデプロイを拒否。DDoS緩和は全プラン。
  - 2026-05 の一括修正は「WAFでは確実に防げない」としてルールを配布しなかった＝パッチ必須。
- Cloudflare: Free Managed Ruleset・カスタムルール5本・レート制限1本・DDoS無制限。Workers は React2Shell の影響外と公式に記載。**支出上限は無い**。暴走はWAF・キャッシュ・CPU上限の設定で抑える（ボット急増時の超過は$6〜15前後の試算・推測）。
- VPS: 前段に Cloudflare 無料プロキシを置けば端の守りは近いが、OS・ミドルウェア・鍵管理・障害対応が全部運営者側。
- 停止への備え: Hobby の停止は課金事故を防ぐ代わりに稼働を失う。止まったときに Pro を1か月だけ使う（約3,300円）かどうかを**先に決めておく**のが現実的（利用者の判断）。

  - 再開する前に **ASP 管理画面の実績を確認する**（㊷の指示どおり）。
  - Vercel を離れて URL が変わるなら、ASP の登録サイトの変更・再審査が要りうる。「`active: true` に戻すだけ」では済まない可能性。
- **広告（AdSense）**: 月約60〜370円。支払い基準額は8,000円で、月190円なら初回入金まで約3.5年。独自ドメインが事実上必要で、表示速度にも響く。**いまは見込みに入れない**。
- **寄付**:
  - Hobby のままで可（Vercel 公式「Asking for Donations does not fall under commercial usage」）。
  - 受け取り先: GitHub Sponsors は日本に対応、個人からのスポンサーは手数料なし。ただしオープンソース貢献が前提。Ko-fi・Buy Me a Coffee の日本での受け取りは未確認。
  - 見込み額は不明（0円もありうる）。入れるなら `app/privacy/page.tsx` の記述と整合させる。
- **データ提供（B2B）**: Annict 由来のデータは第3条の個別許可が前提。市場の価格情報も無い。いまは着手しない。
- **データ源の規約**:
  - AniList: 収益が月$150未満なら無償で商用可。

  - dアニメストア・AI Horde: 規約の原文は未確認。

## 5. 進め方（案。どれも着手前に利用者の判断が要る）
1. **11/25まで**: Annict 第6条への対応方針を決める（§0①の a〜c）。決まったら実装。
2. **今週〜12/05**: 本番を Next 15.5.29 へ上げる PR（#276 の16対応を土台に版だけ下げる）。マージ前にビルドで `.segments` が出ないことを数える。
3. **並行して**: ISR Writes の削減を続ける（Tencent 遮断の効果測定・ボットのデータ更新でのデプロイ削減・自前の計測の削減・再検証を変化した作品だけに絞る）。16 は短期間だけ本番に出して増加率を実測してから判断する。
   - 終わった2026年クールをスナップショット化する案は、①の結論が出るまで保留（公開リポジトリにデータを足すことになる）。
4. **払うと決めた場合**: Cloudflare Workers Paid と VPS を作業ブランチで試作 → 「最悪の月額」と「人の手間」で選ぶ → 独自ドメインと一緒に移行（11月中か2月）→ ASP の実績確認とURL変更 → アフィリエイト再開。
5. **払わないと決めた場合**: Hobby で継続。収益化は寄付だけ。移行の判断は次の引き金で見直す。
   - 公式サイトへのクリックが月150〜200回を超えた
   - 停止（503/402）が再発した
   - 16 への更新が必須になった（15 のサポートが切れる 2027-01-31 の前）
   - Vercel の規約・枠が変わった
