## 0. 送る前に必ず確認すること

| # | 確認事項 | なぜ |
|---|---|---|
| 1 | **宛先メールアドレス**を窓の杜の公式ページ（「情報提供」「編集部へのお問い合わせ」等の窓口）で確認する | この下書きにはアドレスを書いていない。**推測で書かない**方針のため（一次情報で確認できないものは載せない） |
| 2 | 投稿フォームがあるならメールよりそちらを優先する | 編集部の受け口に合わせるほうが読まれる |
| 3 | 本文中の数値が現在も正しいか | 下の数値は2026-08-16時点の実データ。時間が経ったら `content/archive/` を数え直す |
| 4 | 広告（アフィリエイト）について触れているか | `/privacy` に開示済み。隠すと後で問題になるので、聞かれたら正直に答える前提で送る |

**期待値の設定**: 出典の事例は**N=1**で、掲載は編集部の裁量。「送れば載る」ではない。
掲載されても効果は**掲載当日のスパイク**（事例では1〜3人/日 → 165人）で、持続効果は薄い。
費用ゼロ・所要数十分なので、外れても失うものが無いという理由で実行する施策。

## 1. 件名（案）

```
【情報提供】今期アニメを「観られる配信サービス」で絞り込める無料Webサービス「アニメ視聴ガイド」
```

短めの代替案:

```
【情報提供】アニメの配信先を横断検索できる無料Webサービスのご紹介
```

## 2. 本文

```
窓の杜編集部 ご担当者様

はじめてご連絡いたします。個人でWebサービスを開発している〈お名前〉と申します。
自作の無料サービス「アニメ視聴ガイド」について、記事のネタとしてご検討いただけないかと
思いご連絡しました。

■ できること
今期放送中のアニメを一覧し、「dアニメストアで観られる作品だけ」のように
配信サービスで絞り込めます。作品名で検索すると、その作品がどのサービスで
配信されているかが1ページで分かります。
インストール不要・ログイン不要・無料で、スマートフォンでもそのまま使えます。

  https://animedia-khaki.vercel.app

■ 特徴
・国内の配信サービス17社に対応し、放送局とは区別して表示します
  （番組表に載る放送チャンネルを配信サービスとして数えないようにしています）
・曜日別のカレンダー表示があり、カレンダーアプリに購読登録もできます
・過去64クール・配信情報のある1,961作品まで遡って調べられます
・声優1,531人の出演作、制作会社165社・監督378人の作品一覧を横串で見られます
・配信サービス名の名寄せ表をCSV/JSONで公開しており、他の方の開発にも使えます
  （出典表記をお願いする形で無料公開しています）
  https://animedia-khaki.vercel.app/developers

■ 作った理由
「このアニメ、どこで観られるのか」を調べるたびに検索し直すのが面倒で、
自分用に作ったものを公開しました。作品データはアニメ視聴記録サービス
「Annict」のAPIを利用しています。

■ 開発体制
個人開発です。サーバー費用をまかなうため、配信サービスへのリンクの一部に
アフィリエイトを含んでおり、その旨をプライバシーポリシーに明記しています。
  https://animedia-khaki.vercel.app/privacy

ご検討いただけますと幸いです。追加の情報や画像が必要でしたらお送りします。

〈お名前〉
〈メールアドレス〉
〈X等のアカウントがあれば〉
```

  聞かれたら正直に答える。
