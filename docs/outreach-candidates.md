# 見込みユーザー・コミュニティ候補ログ

`outreach-scout` サブエージェント（`.claude/agents/outreach-scout.md`）が実行のたびに追記する累積ログ。
Web検索・WebFetchで見つけた「Discordサーバー」「まとめ/感想サイト」「配信どこ系の困りごと」「Xの公開言及」の
候補を、出典URLつきで一覧化したもの。**このファイルはあくまで候補一覧であり、接触・投稿・DM送信は行わない**
（`docs/sns-growth-research.md` の方針どおり、実際の交流・掲載依頼は人力で行う）。

使い方: 気になる候補があれば、実際にDiscordサーバーに参加して交流する／記事へのコメントや掲載依頼を
手動で送る、といった人力アクションにつなげる。自己宣伝を規制しているコミュニティが多いため、
いきなりURLを貼らず自然な参加から始めること。

起動タイミングの目安: 新クール開始時・SNS施策を見直したいタイミングで随時（`docs/operations.md` 参照）。

## 2026-08-06 — 配信先ウィジェットを貼ってもらう相手（⑯の告知先）

**今回の目的が前回までと違う点**: これまでは「見込みユーザー・拡散してくれるコミュニティ」を
探していたが、今回は`docs/operations.md`⑯で作った**配信先ウィジェットを貼ってくれそうな
個人ブログ**を探した。ウィジェットは存在を知られなければゼロのままなので、⑯の効果は
この告知にかかっている。

**この回の制約（重要）**: サンドボックスから**WebFetchが全ドメインで403**だったため、
各サイトの中身を直接確認できていない。以下は**検索結果のスニペットから判断した候補**で、
「記事末に配信先を書いているか」「問い合わせ導線があるか」は**未確認**。
接触前に必ず人力で1サイトずつ開いて確かめること（このログの内容を確認済みとして扱わない）。

### 相手選びの基準（今回わかった選別軸）

検索で最初に出てくるのは`spocale.com`・`riopon.blog`・`anime-vod.com`・`next-guide.net`・
`uzuhiko.info`のような**VOD比較アフィリエイトサイト**だが、この層は**送っても無駄**。
⑯の前提どおり、彼らがウィジェットを貼ると自分のアフィリエイト収益を他人に渡すことになるので
構造的に貼れない。**競合であって配布先ではない**。

狙うのは「**作品の感想・レビューが主目的で、配信先は読者への親切として書いている**」層。
この層は配信先を毎回手で調べており、そこを1行で埋められることに価値がある。

### プラットフォーム別の貼り付け可否（2026-08-06に検索で確認。実地未検証）

⑯のウィジェットは**HTMLスニペット版**（インラインstyleの`<a>`1個）と**iframe版**の2種類がある。
この2本立てが効くのはここ。

| プラットフォーム | iframe版 | HTMLスニペット版 | 備考 |
|---|---|---|---|
| はてなブログ | ○ | ○ | HTML編集モードでiframe可 |
| ライブドアブログ | ○（見込み） | ○ | |
| FC2ブログ | ○（見込み） | ○ | |
| WordPress（独自ドメイン） | ○ | ○ | |
| アメブロ | **×** | △（要検証） | iframe・script・object・embedは記事内で禁止タグ。YouTube等は例外扱い。`<a>`＋インラインstyleが通るかは未検証 |
| note | **×** | **×** | 記事内に任意のHTMLを置けない。**URLの紹介のみ** |

**アメブロ向けにHTMLスニペット版が通るかは、実際に1本試すまで分からない。** 通らなければ
アメブロ層にはURL紹介のみになる。
