## 指摘
1. **Annict API 利用規約【高】**: 正しいURLは利用規約第1条がリンクする annict.com/terms/api（2026-11-25施行）。第3条で広告・アフィリエイトは明示的に可。第6条で「公開のリポジトリに置くこと」「自分のAPIでの再提供」は禁止＝公開リポジトリの `content/snapshots/`（64件・11MB）と、CORS全開で `/developers` が案内している `/api/season`・`/api/work`・`/api/search-index` が該当しうる。違反時は予告なく失効・遮断されうる（第15条の要旨）。第1段の「2026年クールのスナップショット化」は公開リポジトリにデータを足すことになるので外す。B2Bは「個別許可が前提」。
   - 【監督役】WebFetch で再取得し、第3条・第6条の文と施行日を確認（research/12）。リポジトリが public であることも確認。
2. **Next 15.5.29 が抜けている【高】**: 使い捨てのロックファイルで `npm audit` を回すと next 本体への勧告は無し。15.5.29 は `.segments/` を `experimental.clientSegmentCache`（既定 false）で止めている＝書き込みは14並みの見込み。修正の提供は2027-01-31まで。
   - 【監督役】最初は呼び出し側だけを見て「15.5も書く」と誤読した。関数内の早期 return（app-render.js 2929〜2938行）を読み直し、指摘が正しいと確認。
3. **比べる基準の「Hobby継続」が既に枠を超えている【高】**: Next 14 のままで ISR Writes 130%・Active CPU 89%。超過は「30日経つまで再利用不可」。利用者の条件（セキュリティか収益化に問題があれば月1,000円まで）は既に成立しており、「収益化だけを理由に払わない」は監督役の採算判断で利用者の許容範囲を上書きしている → 払うかは利用者へ返す。停止したら即 Pro 1か月（約3,300円）で止める手順を先に合意しておく。
4. **第1段の実現性【高】**: 9/19〜25の実力は1日2.5〜2.9K単位（月75〜87K）。増加率1.5〜2.0なら113〜174Kで、140K以内は五分以下（推測）。16はマージしないと実測できない＝判定条件が循環。16を48〜72時間だけ本番に出して測る案。打ち手に「自前の計測を減らす」「再検証を変化した作品だけに絞る」を足す。
5. **収益の数字【中】**: リポジトリの一次値は Hulu 2,368円・Prime 845円・ABEMA 902円（content/affiliate/programs.ts）。同じ転換率で約120/490/1,230円。一方で転換率は高すぎる疑い（Prime は新規登録＋7日以内の視聴、Hulu は有料登録が条件）。停止前の約2か月は提携リンクのクリック月3〜5件、8/13時点で成果0件。ASP管理画面の実績が先。AdSense の支払い基準額は8,000円＝月190円なら初回入金まで約3.5年。28クリックは谷の値（10/25時点は47）。
   - 【監督役】programs.ts の rewardYen を確認（Hulu 2,368・Prime 845/836・ABEMA 902）。
6. **Cloudflare を本命とする根拠【中】**: 「ボット200倍でも超過約$6」は要求数だけ。CPU と R2 読み取りを足すと $15前後（推測）。税・ドメイン込みで月約960〜1,020円＝予算の上限ちょうど。R2 にビルドごとのキャッシュが残り続ける可能性。VPS は固定費で、このプロジェクトの事故の主流（従量枠）を型ごと消せる（さくら以外は未調査）。→ 本命を決めずに両案を試作で比べる。
7. **独自ドメイン【中】**: Vercel を離れるなら必須（vercel.app は持ち出せない）。12月の需要の立ち上がりに順位の揺れを重ねない（11月中か2月）。ASP の登録URL変更・再審査が要りうる＝「active: true に戻すだけ」は不正確。
8. **細部【低】**: Next 14 の moderate/low 13件は未レビュー。8/24の停止の主因は ISR Writes ではなく CPU の3.0倍だった可能性。9/24以降は130〜213%でも停止の記録が無く、止まる閾値は分からない。
   - 【監督役】GitHub Actions の直近30日（718回）は実行単位の切り上げで約1,530分（research/14 の作業ファイル runs30.tsv から集計）。非公開リポジトリの無料枠は月2,000分。
